# 동원모빌리티 POP 디자인 시스템 가이드

생산 현장 터치 화면(POP)의 넥사크로 컴포넌트 가이드예요.

**👉 가이드 보기: https://cozyoub.github.io/dongwon-pop-design-system/**

- 컴포넌트별 사용법(xfdl 코드), 구조, 예시, xcss 스타일, 상태, 속성, 토큰
- Light / Dark 미리보기
- 글꼴(Pretendard)과 아이콘이 파일 안에 들어 있어서 `index.html` 하나만 내려받아 열어도 똑같이 보여요

값의 원본은 넥사크로 `ncorePopLight.xcss` / `ncorePopDark.xcss`예요.

Pretendard는 SIL Open Font License 1.1로 배포되는 글꼴이에요.
